# PACWATCH Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build PACWATCH — a zero-install, offline-capable maritime awareness web app used as the Tier 3 capstone of a one-day "coding with AI" course for ~40 Marines, with a six-level upgrade ladder baked into the repo.

**Architecture:** A static `file://` web app (no server, no build step, no package manager) rendering real Hawaii geographic data as vector GeoJSON in Leaflet, replaying a synthetic-but-realistic AIS scenario, with a client-side tool-calling agent panel. A separate Python build pipeline (`tools/`) fetches and processes real public-domain geo data into browser-loadable `data/*.js` globals; that pipeline runs on the instructor's machine only and never ships to students.

**Tech Stack:** Vanilla JS (ES2020, no framework, no bundler) · Leaflet 1.9.4 (vendored) · Python 3.12 + numpy + matplotlib + shapely (build-time only) · `node --test` (repo-only test runner) · zero runtime dependencies.

---

## Global Constraints

These apply to **every** task. Violating any of them breaks the core design.

1. **No `fetch()` for local data, ever.** `file://` blocks it. Every data file is a `.js` that assigns a `const` global and is loaded via `<script>`. The only network call in the entire app is the chat completion.
2. **No build step, bundler, transpiler, or package manager in the student path.** No `import`/`export` ES module syntax in `js/` — `file://` blocks module loading without a server. Plain `<script>` tags and globals only.
3. **Dual-loadable JS.** Every file in `js/` ends with exactly this line so `node --test` can require it:
   ```js
   if (typeof module !== 'undefined') module.exports = /* the file's main global */;
   ```
4. **Every source file readable in one sitting.** Hard ceiling 250 lines per file in `js/`. If a file exceeds it, split it.
5. **Bounding box is fixed:** `[-160.0, 20.8, -157.0, 22.4]` (west, south, east, north). All geo data clipped to it.
6. **Coordinates:** lat/lon rounded to 5 decimal places. Never more — it doubles file size for sub-meter precision nobody needs.
7. **Total unzipped student payload < 1 MB.** Verified by an automated check in Task 19.
8. **No AI attribution** in any commit message, file header, doc, or repo content.
9. **No secrets committed.** `config.js` is gitignored; `config.example.js` ships with an empty key.
10. **Never assert intent.** Every detector returns `confidence` and `alternative_explanations`. The agent system prompt forbids intent claims. This is a functional requirement, not a doc note.
11. **Naming:** the product is `PACWATCH` (all caps) in UI copy, `pacwatch` in paths/identifiers.

## Shared Data Contracts

Every task depends on these. They are defined once, here.

### `SCENARIO` — `data/scenario.js`

```js
const SCENARIO = {
  meta: {
    name: "PACWATCH Replay — Oahu / Kauai",
    bbox: [-160.0, 20.8, -157.0, 22.4],
    start_epoch: 1754402400,   // integer seconds UTC, = 0400 local HST
    step_seconds: 120,
    steps: 121,                // t index runs 0..120 inclusive → 4h00m
    tz_offset_hours: -10,      // HST, no DST
    provenance: "Traffic patterns derived from public-domain Marine Cadastre AIS. Four vessels are synthetic."
  },
  vessels: [ /* Vessel objects, see below */ ]
};
```

### `Vessel`

```js
{
  mmsi: 366123456,             // integer, unique
  name: "MATSON KAUAI",        // uppercase
  callsign: "WDE2345",
  type: "cargo",               // one of: cargo tanker fishing tug passenger sailing research other
  flag: "US",                  // ISO-3166 alpha-2
  length_m: 218,               // integer
  beam_m: 32,                  // integer
  draft_m: 11.2,               // 1 decimal
  destination: "HONOLULU",     // uppercase, free text
  nav_status: "under way using engine",
  track: [ [t, lat, lon, sog, cog], /* ... */ ]
}
```

**`track` row format — memorize this, it is used everywhere:**

| Index | Field | Type | Notes |
|---|---|---|---|
| 0 | `t` | integer | Step index `0..120`. Wall-clock = `meta.start_epoch + t * meta.step_seconds`. |
| 1 | `lat` | float | 5 decimals |
| 2 | `lon` | float | 5 decimals, negative (western hemisphere) |
| 3 | `sog` | float | Speed over ground, knots, 1 decimal |
| 4 | `cog` | integer | Course over ground, degrees true, `0..359` |

Rows are sorted ascending by `t`. **A reporting gap is represented by absent rows** — no null, no sentinel. This is deliberate: it is visible to a beginner reading the file, and it forces the gap detector to reason about missing data rather than filtering a flag.

### `Finding` — returned by every detector

```js
{
  detector: "loitering",              // detector id
  mmsi: 366123456,
  t_start: 34,                        // step index
  t_end: 59,
  confidence: 0.72,                   // 0.0–1.0
  evidence: [                         // human-readable, specific, quantitative
    "Speed held between 1.1 and 2.8 kts for 50 minutes (t=34..59).",
    "All positions within a 1.4 nm radius.",
    "Broadcast destination HONOLULU, 18 nm away, with no closing course."
  ],
  alternative_explanations: [         // REQUIRED, non-empty. See Global Constraint 10.
    "Mechanical trouble.",
    "Waiting for a pilot or berth availability.",
    "Legitimate fishing activity."
  ]
}
```

### `DETECTORS` registry — `js/detect.js`

```js
const DETECTORS = [
  { id:"loitering",  label:"Loitering",             fn: detectLoitering,  implemented:true  },
  { id:"rendezvous", label:"Rendezvous",            fn: detectRendezvous, implemented:false },
  { id:"gap",        label:"Reporting gap in zone", fn: detectGap,        implemented:false },
  { id:"identity",   label:"Identity inconsistency",fn: detectIdentity,   implemented:false }
];
```

Each `fn` has signature `fn(scenario) -> Finding[]`. Unimplemented stubs `return []`.
`runAllDetectors(scenario) -> Finding[]` concatenates results from entries where `implemented === true`.

### `TOOLS` registry — `js/tools.js`

```js
const TOOLS = [
  { schema: { name, description, parameters /* JSON Schema */ }, fn: (args) => any }
];
```
Plus `callTool(name, argsObject) -> any` which throws `Error("unknown tool: " + name)` on a miss.

### Layer registry — `js/layers.js`

```js
const LAYERS = [
  { id:"coast", label:"Coastline & Land", enabled:true,  build: () => /* L.Layer */ },
  { id:"bathy", label:"Depth Contours",   enabled:false, build: () => /* L.Layer */ }
];
```

**Deviation from spec §5, deliberate:** the spec said students *uncomment a line*. Use an `enabled:` boolean instead. A half-completed uncomment produces a syntax error and a white screen, which at a 40:1 student-to-instructor ratio is a support call. Flipping `false` → `true` cannot break the parse. Same one-token edit, same "one line" feel, no failure mode.

- [ ] **Step 1: Write `tools/geoutil.py`**

```python
"""Shared helpers for the PACWATCH data pipeline."""
import json, os

BBOX = (-160.0, 20.8, -157.0, 22.4)  # west, south, east, north

def write_js_global(path, varname, obj, note=None):
    """Write obj as `const <varname> = {...};` plus a Node export shim."""
    os.makedirs(os.path.dirname(path), exist_ok=True)
    body = json.dumps(obj, separators=(',', ':'))
    header = f"// {note}\n" if note else ""
    with open(path, 'w') as f:
        f.write(f"{header}const {varname} = {body};\n"
                f"if (typeof module !== 'undefined') module.exports = {varname};\n")
    return os.path.getsize(path)

def round_coords(obj, nd=5):
    """Recursively round every float in a GeoJSON coordinate structure."""
    if isinstance(obj, float):
        return round(obj, nd)
    if isinstance(obj, list):
        return [round_coords(x, nd) for x in obj]
    if isinstance(obj, dict):
        return {k: round_coords(v, nd) for k, v in obj.items()}
    return obj
```

- [ ] **Step 2: Write `tools/fetch_coastline.py`**

Requirements, in order:
1. Download `https://raw.githubusercontent.com/martynafford/natural-earth-geojson/master/10m/physical/ne_10m_land.json` and `.../ne_10m_minor_islands.json` to a cache dir (`tools/.cache/`), skipping the download if the file already exists.
2. Load both with `json`, build shapely geometries.
3. Intersect every feature with `shapely.geometry.box(*BBOX)`; discard empties.
4. `simplify(tolerance=0.0008, preserve_topology=True)` — approximately 90m, invisible at the zoom levels in use.
5. Drop resulting polygons whose area is below `1e-6` square degrees (removes specks that are just noise at this scale).
6. Emit a `FeatureCollection` with a `name` property, using the largest-island heuristic to label Oahu, Kauai, Molokai, Lanai, Maui, Niihau by nearest centroid to known coordinates.
7. `write_js_global('data/geo-coast.js', 'GEO_COAST', fc, note='Natural Earth 10m (public domain), clipped and simplified.')`
8. Print the output byte size.

Assert before writing: output must be under 80,000 bytes. If it is larger, raise the simplify tolerance and re-run rather than shipping it.

```python
# tests/test_pipeline.py
import json, os, re, unittest

BBOX = (-160.0, 20.8, -157.0, 22.4)

def load_js_global(path):
    src = open(path).read()
    m = re.search(r'^const \w+ = (.*);$', src, re.M)
    return json.loads(m.group(1))

class TestCoastline(unittest.TestCase):
    PATH = 'data/geo-coast.js'

    def test_exists_and_small(self):
        self.assertTrue(os.path.exists(self.PATH))
        self.assertLess(os.path.getsize(self.PATH), 80_000)

    def test_is_feature_collection(self):
        fc = load_js_global(self.PATH)
        self.assertEqual(fc['type'], 'FeatureCollection')
        self.assertGreater(len(fc['features']), 0)

    def test_all_coords_within_bbox(self):
        fc = load_js_global(self.PATH)
        def walk(c):
            if isinstance(c[0], (int, float)):
                lon, lat = c[0], c[1]
                self.assertTrue(BBOX[0] - 0.01 <= lon <= BBOX[2] + 0.01, f'lon {lon}')
                self.assertTrue(BBOX[1] - 0.01 <= lat <= BBOX[3] + 0.01, f'lat {lat}')
            else:
                for x in c: walk(x)
        for f in fc['features']:
            walk(f['geometry']['coordinates'])

    def test_oahu_present(self):
        fc = load_js_global(self.PATH)
        names = {f['properties'].get('name') for f in fc['features']}
        self.assertIn('Oahu', names)

if __name__ == '__main__':
    unittest.main()
```

- [ ] **Step 1: Write `tools/fetch_bathymetry.py`**

Requirements:
1. Fetch the GMRT ESRI ASCII grid for the bbox, cached to `tools/.cache/gmrt.asc`:
   ```
   https://www.gmrt.org/services/GridServer?minlongitude=-160.0&maxlongitude=-157.0&minlatitude=20.8&maxlatitude=22.4&format=esriascii&resolution=low&layer=topo
   ```
2. Parse the six-line ASCII header (`ncols`, `nrows`, `xllcorner`, `yllcorner`, `cellsize`, `nodata_value`) then `numpy.loadtxt(..., skiprows=6)`. Mask `nodata_value`.
3. Build lon/lat axes from the header. **ESRI ASCII rows run north → south**, so the first data row is the *top* of the grid; flip the array vertically so it matches an ascending-latitude axis.
4. Use `matplotlib.pyplot.contour(lons, lats, elevation, levels=[-3000, -1000, -200])` with a non-interactive backend (`matplotlib.use('Agg')`).
5. Extract paths from the contour set. Convert each to a shapely `LineString`, `simplify(0.002, preserve_topology=False)`, and discard lines with fewer than 4 points or length under 0.02 degrees.
6. Emit `depth_m` as the positive depth (`200`, `1000`, `3000`).
7. `write_js_global('data/geo-bathy.js', 'GEO_BATHY', fc, note='Derived from GMRT (Global Multi-Resolution Topography). Free use.')`

Assert output under 140,000 bytes; raise the simplify tolerance if exceeded.

**Note on matplotlib version:** `contour(...).collections` is removed in matplotlib 3.10+. Use `cs.allsegs` (a list of per-level segment lists), which is stable across versions:
```python
for level, segs in zip(cs.levels, cs.allsegs):
    for seg in segs:  # seg is an (N,2) array of [lon, lat]
        ...
```

- [ ] **Step 1: Write `positionAt` first — it is the one piece of real logic**

```js
// Returns {lat, lon, sog, cog, stale} for a vessel at step t, or null if the
// vessel has no report at or before t. `stale` is true when the most recent
// report is older than t — i.e. the vessel is inside a reporting gap.
function positionAt(vessel, t) {
  let last = null;
  for (const row of vessel.track) {
    if (row[0] > t) break;
    last = row;
  }
  if (!last) return null;
  return { lat: last[1], lon: last[2], sog: last[3], cog: last[4], stale: last[0] !== t };
}
```

```js
async function runAgent(userText, onEvent, transport = fetch) {
  AgentState.messages.push({ role: 'user', content: userText });
  for (let i = 0; i < CONFIG.maxToolIterations; i++) {
    const res = await transport(CONFIG.endpoint, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json',
                 'Authorization': 'Bearer ' + CONFIG.apiKey },
      body: JSON.stringify({
        model: CONFIG.model,
        messages: [{ role:'system', content: CONFIG.systemPrompt }, ...AgentState.messages],
        tools: toolSchemas(),
      }),
    });
    if (!res.ok) throw new Error('model request failed: ' + res.status);
    const msg = (await res.json()).choices[0].message;
    AgentState.messages.push(msg);

    if (!msg.tool_calls || msg.tool_calls.length === 0) {
      onEvent({ type: 'answer', text: msg.content });
      return msg.content;
    }
    for (const tc of msg.tool_calls) {
      let result;
      try {
        result = callTool(tc.function.name, JSON.parse(tc.function.arguments));
      } catch (err) {
        result = { error: String(err.message) };
      }
      onEvent({ type: 'tool', name: tc.function.name, args: tc.function.arguments, result });
      AgentState.messages.push({
        role: 'tool', tool_call_id: tc.id, content: JSON.stringify(result),
      });
    }
  }
  const bail = 'I could not complete that in the allowed number of steps.';
  onEvent({ type: 'answer', text: bail });
  return bail;
}
```

```python
# tests/test_build.py
import os, subprocess, unittest, zipfile

class TestBuild(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        env = dict(os.environ, PACWATCH_API_KEY='test-key-not-real')
        subprocess.run(['python3','tools/build_zip.py'], check=True,
                       capture_output=True, env=env)

    def test_zip_exists_and_is_small(self):
        self.assertTrue(os.path.exists('dist/pacwatch.zip'))
        self.assertLess(os.path.getsize('dist/pacwatch.zip'), 400_000)

    def test_unzipped_under_one_megabyte(self):
        with zipfile.ZipFile('dist/pacwatch.zip') as z:
            total = sum(i.file_size for i in z.infolist())
        self.assertLess(total, 1_048_576, f'payload is {total} bytes')

    def test_no_instructor_or_tooling_shipped(self):
        with zipfile.ZipFile('dist/pacwatch.zip') as z:
            names = z.namelist()
        for bad in ['instructor/', 'tools/', 'tests/', '.git/', 'superpowers/']:
            self.assertFalse(any(bad in n for n in names), f'{bad} leaked into the zip')

    def test_answer_key_absent(self):
        with zipfile.ZipFile('dist/pacwatch.zip') as z:
            blob = b''.join(z.read(n) for n in z.namelist() if n.endswith(('.js','.md','.html')))
        for word in [b'ANSWER-KEY', b'KAIMANA HOU is the loiter']:
            self.assertNotIn(word, blob)

    def test_build_fails_without_key(self):
        env = {k: v for k, v in os.environ.items() if k != 'PACWATCH_API_KEY'}
        r = subprocess.run(['python3','tools/build_zip.py'], capture_output=True, env=env)
        self.assertNotEqual(r.returncode, 0, 'build must refuse to ship without a key')
```

# As-built notes

Recorded after implementation. Where the build differs from the plan above, the
build is correct and this section says why.

| # | Planned | Built | Why |
|---|---|---|---|
| 1 | Each `js/` file ends with a `module.exports` shim | No shim; tests load files into a shared VM context via `tests/load.js` | A `var X = require(...)` in a dependent file collides with a global `const X` from an earlier script and throws at parse time in the browser. The VM loader reproduces the browser's shared global scope exactly and keeps student-facing files free of test scaffolding. |
| 2 | Students uncomment a layer line | Students flip `enabled: false` → `true` | A half-finished uncomment is a syntax error and a white screen. At 40:1 that is a support call. A boolean cannot break the parse. |
| 3 | 15 layers incl. a separate place-names layer | 15 layers, names folded into `assets` | One toggle giving dots *and* labels is better than two toggles that are only useful together. |
| 4 | Coastline from Natural Earth 10m | OpenStreetMap primary, Natural Earth fallback | NE 10m is 1:10M scale: 279 points for four islands, and neither Pearl Harbor's lochs nor Kaneohe Bay exist in it. Those are features the app labels. OSM gives 2,651 points in 60 KB. |
| 5 | 121 weather frames | 13 frames, one per 20 minutes | 121 frames cost 348 KB — three times the entire environmental budget — to encode a field that does not change on a two-minute timescale. |
| 6 | `start_epoch: 1754380800` | `1754402400` | The planned value put step 0 at 2200 local, not 0400. |
| 7 | Exercise Area BRAVO at `-159.95..-159.60` | `-159.99..-159.82` | The original box put a third of the "exercise area" on top of Kauai. |
| 8 | Gap implies ~31 kt | 31.0 kt (first generated pass produced 94.5 kt) | 94 kt is not a suspicious vessel, it is an obviously fabricated one. The first student to do the arithmetic stops believing the scenario. |
| 9 | Near-miss pair "over the CPA threshold" | 533 m apart | The first generated pass had them 32 m apart at 18 and 12.5 kts, which is a collision, not a near-miss. |
| 10 | `node --test tests/` | `tools/run-tests.sh` | Node 22 does not glob a bare directory. The script also runs the Python suite. |
